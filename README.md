# リサーチエージェント(エージェントのループと止める条件)

質問を受け取り、検索ツールを使って答えをまとめるエージェント。LLM も検索もモックで、外部 API は呼ばない。

## 要件

- ループは最大3回。回数の指定がなければ3回、指定があればその回数にする
- 上限で止まったらエラーメッセージを返す。内容は、なぜ上限で止まったかの理由
- 検索のモックが返すものは、お任せ
- 同じ言葉で2回続けて検索しようとしたら、上限の前でも止める。止まった理由は「同じ検索の繰り返し」
- 上限が 0 や負の数なら、動かす前にエラーで知らせる

## 動かし方

Node.js 24 で動く(依存パッケージは無いので `npm install` は要らない)。

```bash
npm run agent -- --max 5 --llm answer-after-2
```

| 引数 | 意味 |
| --- | --- |
| `--max <回数>` | 検索の最大実行回数(1 以上)。省くと 3 |
| `--llm answer-after-<N>` | N 回検索したら答える LLM モック(省くと `answer-after-2`) |
| `--llm never` | 毎回「もっと検索する」を選び、答えを出さない LLM モック |
| 引数の残り | 質問(省くと既定の質問) |
